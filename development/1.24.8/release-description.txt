- **Greetings stay simple:** hello, thanks, help and quick questions no longer start a project task or checklist.

✅ Tasks follow your goal
- **Meaningful task names:** checklists describe what you want accomplished, rather than tool names such as list_commands. Old saved command-list tasks are cleared.
- **Continue keeps the plan:** real work retains its original goal and project guidance when you ask to continue.

🎨 Cleaner checklist text
- **Readable labels:** chat timestamps no longer get copied against the task name. Times written inside your instructions stay intact.

🧪 Regression checks
- Automated checks cover quick requests, task retention, command schemas, startup, Studio detection fixtures, updating and Windows/Mac builds. Live AI accounts, response speed and real Studio sessions were not tested.
